# M5 — every instrument live at speed

`2026-08-29-m5-hud-at-speed.png` — `tools/drive_capture.gd --ticks 330 --hold
accelerate`: the title and hints top-left; TIME running in green over its
label with BEST holding the yellow placeholder top-right; the minimap inset
bottom-left, orientation-fixed with the start band, props, the red kart disc
and the yellow true-heading arrow; the half-dial bottom-right with the
red→yellow needle swept to the kart's speed. Deterministic: named seed, fixed
ticks.

The first attempt at this capture caught a real bug the headless suites had
passed over: anchored controls placed with `position` (relative to the
parent's top-left, whatever the anchors say) rendered off-screen — only the
top-left title block survived. The layout now uses anchor offsets, and the
HUD and minimap suites assert on-screen rects, so the class is gated.

Noted for the M6 look pass: the minimap's ground reads washed-out — the
orthographic camera at 100 wu looks down through fog that starts at 50 wu.
The GDD says "a live top-down view" and no more; whether the minimap camera
should see fog is an M6 decision.
