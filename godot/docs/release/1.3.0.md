# Low Poly Cart 1.3.0 — release record

The soundtrack release: everything in 1.2.0 plus M10 complete. The game has
a voice — a synthesized, committed, byte-reproducible cue set played from a
simulation that publishes every sound as data:

- **The engine note** rises and falls with the speed ratio (pitch and
  volume are specified curves, live-tunable like everything else).
- **Impacts** scale with the velocity destroyed and sound from where they
  happened; the boundary **rebound** is deliberately a different sound; a
  pin is one thump, not a drum roll.
- **The race speaks**: countdown ticks and a GO an octave up, a chirp
  through each gate, a fanfare on the banked lap, brighter for a new best,
  a chord for a medal.
- **Silence keeps promises** (normative, tested): ignored gate passes,
  LOADING, focus loss, and Reset Kart all say nothing.
- **M mutes** (session-only; output-gated — the deterministic cue stream is
  provably unaffected).
- Acceptance item 16: the cue stream is byte-identical at 30/60/144 fps,
  carried by the probe record's per-pass hashes.

## §14 ladder, as run for this release

**Phase 0 — gate.** `tools/test.sh` green at the tagged commit: 28 suites,
checkers, bench, nine-state gallery; coverage 82 scenarios — 81 verified,
1 visual, 0 deferred; G2 at sixteen items.

**Phase 1 — export.** Built from one commit via `tools/export_all.sh`;
sizes and SHA-256s in `docs/progress/2026-09-04-v1.3.0-export-record.txt`.
Web payload 19.72 MB gzip-9 against the 25 budget (the audio costs 156 KB).
Known issue, Backlogged: the Web preset's empty exclude filter can pack
gitignored `gallery/` scratch — this build was cut from a clean tree and
verified against the recorded sizes.

**Phase 2 — smoke.** The signed macOS artifact smoked itself (exit 0,
banked 17.93 s lap). **Windows: built and checksummed, NOT smoke-tested
here** — same standing instruction as prior releases. Note: the smoke is
headless-style and proves nothing about audio output; the owner's listen
test on this machine is the audio evidence.

**Phase 3 — sign.** macOS signed with Developer ID Application (hardened
runtime, timestamp); verify passes. **Not notarised in this run** — the
owner's keychain holds credentials; supply the `--keychain-profile` name
and the 1.1.0 record's commands apply unchanged. Recipients right-click →
Open until then. Windows unsigned (SmartScreen: "More info → Run anyway").

**Phase 4 — tag.** `config/version` 1.3.0; annotated tag `v1.3.0` on the
build commit.
