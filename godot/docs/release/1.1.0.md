# Low Poly Cart 1.1.0 — release record

The circuit release. Everything in 1.0.0 plus M9 complete: the game is now
a game — the shipped seven-gate ring circuit **first-light** is the boot
world, laps bank only when the course is threaded (no minimum lap time),
gates are directional furniture readable from either side, `G` restarts the
attempt, bests are per-circuit, and medal targets (gold 20.5 / silver 23.0 /
bronze 25.5) show on the banked lap. Coverage: 73 GDD scenarios — 72
verified, 1 visual, 0 deferred; G2 at fifteen conformance items; the
ambiguity register at fifteen entries (A15 the newest), none open. Two owner
playtests and an adversarial Critic pass ([REJECTED] on record drift, then
[APPROVED]) closed the milestone.

## §14 ladder, as run for this release

**Phase 0 — gate.** `tools/test.sh` green at the tagged commit: 25 suites,
the checkers, the bench, the nine-state gallery.

**Phase 1 — export.** Distribution targets built from one commit via
`tools/export_all.sh`; sizes and SHA-256s in
`docs/progress/2026-08-31-v1.1.0-export-record.txt`.

**Phase 2 — smoke.** The macOS artifact smoked itself (`LPC_SMOKE=1`: boot
into first-light → GO → the baked drive threads all seven gates → banked
22.00 s lap → clean exit 0), after signing. **Windows: built and
checksummed, NOT smoke-tested here** (no Windows machine); before wide
distribution someone on Windows should run
`set LPC_SMOKE=1 && lowpolycart.exe` and see exit code 0, or simply play a
lap.

**Phase 3 — sign.** macOS app signed with Developer ID Application
(hardened runtime, secure timestamp); `codesign --verify --deep --strict`
passes. **NOT notarised** — this machine holds no App Store Connect
credentials — so recipients on other Macs WILL hit Gatekeeper ("cannot be
opened / unverified developer") until notarisation is done, and must
right-click → Open (twice) or `xattr -d com.apple.quarantine` to play. To
notarise before sharing widely, the credential holder runs:

```
xcrun notarytool store-credentials AC_PASSWORD --apple-id <id> --team-id <team-id>
xcrun notarytool submit build/dist/LowPolyCart-macos-1.1.0.zip --keychain-profile AC_PASSWORD --wait
xcrun stapler staple build/macos/LowPolyCart.app
# then re-zip the stapled app for distribution
```

Windows is unsigned (no code-signing certificate for Windows on this
machine); SmartScreen may warn on first run — "More info → Run anyway".

**Phase 4 — tag.** `config/version` 1.1.0; annotated tag `v1.1.0` on the
build commit.

## The distribution files

Under `godot/build/dist/` (not committed; regenerable from the tagged
commit): `LowPolyCart-macos-1.1.0.zip` (signed universal .app, made with
`ditto -c -k --keepParent` so the signature survives) and
`LowPolyCart-windows-1.1.0.zip` (x86_64 `lowpolycart.exe` + its
`lowpolycart.pck` — keep the two files together in one folder).
