# Low Poly Cart 1.2.0 — release record

The feedback release: everything in 1.1.0 plus `retune-handling-and-line-
clearance`, responding to the first outside-user reports (owner-approved by
playtest, 2026-09-01):

- **25% faster everywhere** — `accel`/`maxSpeed`/`turnRate`/`steerThreshold`
  scaled uniformly (GDD amendment 3e0c98c). The uniform scale preserves
  every dial anchor, every acceptance timing, and the turning radius, so
  the checklist's numbers are unchanged; top speed is 15 wu/s.
- **Steering eases in** — `steerEaseSeconds` (0.12 s) linear ramp on onset,
  resetting on release or reversal; peak rate up 25%. The jerk was the step
  function; the step function is gone.
- **The invisible wall is gone** — the 48°-yaw tree whose collision box
  left 0.12 wu of racing-line clearance is dropped by the new curation
  rule: every prop's worst-case collision AABB must clear the racing-line
  corridor (baked arc ∪ tight line through the gates) by `lineClearanceWu`.
  52 props remain; the closest is 1.74 wu off the corridor.
- Lap re-bakes at **17.92 s**; targets gold 16.5 / silver 19.0 /
  bronze 21.5.

## §14 ladder, as run for this release

**Phase 0 — gate.** `tools/test.sh` green at the tagged commit: 26 suites,
checkers, bench, nine-state gallery.

**Phase 1 — export.** Built from one commit via `tools/export_all.sh`;
sizes and SHA-256s in `docs/progress/2026-09-01-v1.2.0-export-record.txt`.

**Phase 2 — smoke.** The signed macOS artifact smoked itself: boot into
first-light → GO → the baked drive threads all seven gates → banked
17.93 s lap → exit 0. **Windows: built and checksummed, NOT smoke-tested
here** (no Windows machine) — same standing instruction as 1.1.0.

**Phase 3 — sign.** macOS signed with Developer ID Application (hardened
runtime, timestamp); verify passes. **Not notarised in this run** — the
owner holds notarisation credentials in the keychain; the submit/staple
commands from `docs/release/1.1.0.md` apply unchanged once the
`--keychain-profile` name is supplied. Until then, recipients right-click →
Open past Gatekeeper. Windows remains unsigned (SmartScreen: "More info →
Run anyway").

**Phase 4 — tag.** `config/version` 1.2.0; annotated tag `v1.2.0` on the
build commit.
